🎓 University Admission Predictor — Basic Description

The University Admission Predictor is a Machine Learning project that predicts a student's estimated probability of admission based on their academic and profile information.

🔹 How the project works

The user enters information such as:

GRE Score – Graduate Record Examination score
TOEFL Score – English proficiency score
University Rating – Rating of the university
SOP – Statement of Purpose rating
LOR – Letter of Recommendation rating
CGPA – Undergraduate academic performance
Research Experience – Whether the student has research experience

The trained machine learning model processes these inputs and produces an estimated admission probability.

🔹 Project Workflow
Student Information
       ↓
Data Preprocessing
       ↓
Feature Selection
       ↓
Machine Learning Model
       ↓
Prediction
       ↓
Estimated Admission Probability
🔹 Purpose of the Project

The main purpose is to help students understand their estimated admission chances based on their academic profile. It is an educational ML application and does not represent an actual university admission decision.
